# Astrava Studios

Independent software and product engineering studio based in Palma de Mallorca, Spain. Founded in 2026.

We build web and mobile applications, SaaS platforms, AI-powered tools and automation.

## Products

- **Qavra**, an academic social platform for students in Azerbaijan, built in partnership with InnoHub. [qavra.app](https://qavra.app)
- **LuckySwipe**, a swipe-based number selection app for Spanish lotteries. [luckyswipe.app](https://luckyswipe.app)
